SPL

Sparse Pragmatic Language.
모든 키워드가 정확히 4바이트로 설계된 초고수밀도 미니멀리즘 언어.

01. 핵심 규칙

SPL은 극도의 일관성을 추구합니다.

4바이트 규칙: 모든 유효한 키워드는 줄의 시작 부분에서 정확히 4바이트를 차지해야 합니다.

공백조차 규칙의 일부입니다. 예를 들어 set은 뒤에 공백 하나를 포함하여 set_ 또는 set 가 됩니다.

; 이것은 주석입니다
varl pi   3.14  ; 상수 선언
varm cnt  0     ; 변수 선언
prnt "Hello"    ; 출력

02. 변수와 대입

값을 저장하고 업데이트하는 방법입니다.

키워드 의미 예시
varl 불변 (Constant) varl pi 3.14
varm 가변 (Mutable) varm x 10
set_ 값 업데이트 set_ x 20

03. 계산하기

SPL의 산술 연산은 3개의 인자를 받습니다: 대상, 값A, 값B

add_ sum 10 20  ; sum = 10 + 20
mul_ res sum 2  ; res = sum * 2
sub_ x res 5    ; x = res - 5
prnt x          ; 55 출력

04. 흐름 제어

조건문과 반복문 역시 4바이트 키워드를 사용합니다.

varm i 1
loop i <= 5
  prnt i
  add_ i i 1
end_

if__, elif, else 블록은 항상 end_로 닫습니다.

05. 함수

코드의 재사용성을 높입니다.

func square(n)
  mul_ r n n
  retn r
end_

varm result call square(5)
prnt result     ; 25 출력
